# 쿠팡 주문 취소 (반품접수 + 출고중지완료) 자동화

발주서의 `취소준비` + `판매처=쿠팡` 주문을 쿠팡윙 배송관리에서 찾아 반품접수하고, 이어서 출고중지완료까지 처리한다.

쿠팡윙 **주문번호**와 발주서 **묶음번호**는 체계가 달라 매칭에 쓸 수 없다 — **수취인명 + 상품명**으로 대조한다.

## 실행 절차

### 1단계 — 드라이런

```bash
npm run coupang:cancel
```

크롬 실행·로그인 대기·목록 수집·대조까지 자동으로 하고, 1건을 **접수 직전까지만** 진행한 뒤 멈춘다.

- 크롬이 안 떠 있으면 전용 프로필(`.browser-profiles/coupang-wing`)로 자동 실행된다. 로그인 세션이 남아 있어 보통 바로 통과한다.
- 로그인이 안 돼 있으면 스크립트가 대기한다 → 사용자에게 크롬 창에서 로그인하라고 안내한다.

### 2단계 — 보고

대조 결과(매칭 N건 / 중복후보 / 미발견)와 드라이런 스크린샷을 사용자에게 보고한다.
스크린샷은 `.cancel-shots/`에 저장된다. Read로 열어 확인하고, 수량·환불예정금액·입력값을 표로 정리해 보여준다.

### 3단계 — 전건 접수

사용자 승인 후 실행한다. 40건 기준 약 12분이라 `run_in_background`로 돌린다.

```bash
npm run coupang:cancel -- --go
```

접수 성공한 건만 발주서를 `취소준비` → `취소완료`로 바꾼다.

### 4단계 — 출고중지완료

접수한 주문은 **출고중지 요청**에 쌓인다. 여기서 `출고중지완료`를 눌러야 환불까지 최종 처리된다.

```bash
node scripts/coupang-stop-complete.mjs --dry   # 확인창까지만 열고 취소
node scripts/coupang-stop-complete.mjs         # 전건 처리
```

- 대상은 배송상태 `상품준비중` + 출고중지 완료일 `출고중지 전`인 행만. 이미 출고된 건(`이미출고` 대상)은 건드리지 않는다.
- 확인창 안내가 "출고중지완료하시면 환불이 완료됩니다"라 **되돌릴 수 없다**. 반드시 승인을 받고 실행한다.
- 이 목록은 10건씩만 보여주고 페이지 크기 변경 수단이 없다. 처리한 행은 목록에서 빠지므로 1페이지를 반복해 훑는 구조다(회차당 최대 10건 일괄).

## 반품접수 창 고정 입력값

| 항목 | 값 |
|---|---|
| 반품접수수량 | 발주서 수량 전량 |
| 반품사유 | 판매자사유 → 배송 지연 (`LATEDELIVERED`) |
| 상세사유 | 배송 장기 지연 |
| 배송비 부담주체 | 판매자 |
| 반품상품 회수여부 | 회수가 불필요합니다 |
| 상품 회수지 | 배송지 동일 |

바꾸려면 `scripts/coupang-cancel.mjs`의 `REASON_CODE` / `REASON_DETAIL` 상수를 고친다.

## 주의사항

- **반품접수는 완료 후 수정 불가**다. 드라이런 확인 없이 `--go`를 먼저 돌리지 않는다.
- 매 건마다 주문번호·수취인명·상품명·배송상태(`상품준비중`)를 대조하고, 하나라도 어긋나거나 검색 결과가 1건이 아니면 그 건은 건너뛰고 실패로 기록한다. 실패는 `scripts/_cancel-results.json`과 실패 스크린샷으로 남는다.
- 이미 사용자가 직접 접수·처리한 건은 상품준비중 목록에서 빠져 "검색 결과 0건"으로 실패 기록된다. 정상이며, 발주서 상태만 따로 맞춰주면 된다.
- 쿠팡윙 조회 기간은 **최근 30일**로 고정한다. 31일 이상을 넘기면 빈 결과가 돌아온다.
- 목록 로딩은 고정 대기로 판단하지 않는다. 행이 그려지거나 빈 목록 안내가 뜰 때까지 기다린다 — 로딩 중 0행을 "없음"으로 오판하면 처리가 조용히 누락된다.

## 구성 파일

| 파일 | 역할 |
|---|---|
| `scripts/coupang-cancel-run.mjs` | 전체 파이프라인 러너 (`npm run coupang:cancel`) |
| `scripts/_cancel-list.mjs` | 발주서에서 취소준비+쿠팡 추출 |
| `scripts/_wing-collect.mjs` | 쿠팡윙 상품준비중 목록 수집 |
| `scripts/_wing-match.mjs` | 수취인명·상품명 대조 |
| `scripts/coupang-cancel.mjs` | 반품접수 실행 (`--dry`로 1건 접수 직전까지) |
| `scripts/coupang-cancel-apply.mjs` | 발주서 취소완료 반영 |
| `scripts/coupang-stop-complete.mjs` | 출고중지완료 일괄 처리 (`--dry`로 확인창까지만) |
