# 상품 필수정보·이미지 전면 재정비 설계

날짜: 2026-08-22
상태: 사용자 승인 대기

## 배경

- 쿠팡/스마트스토어 등에서 **이미지 저작권 침해 + 필수표기 누락** 신고 메일이 반복 수신됨 (예: 비락식혜 건, 2026-08-07)
- 원인 1: 플레이오토 내보내기 시 상품정보제공고시가 전부 `"상세페이지 참조"`로 하드코딩됨 (`app/api/products/playauto-export/route.ts:334`, `lib/playauto-schema.ts`)
- 원인 2: 썸네일/상세이미지를 원본 판매처에서 복사해 사용 → 저작권 문제
- DB에는 필수정보(제조사, 원산지 등)를 저장할 컬럼 자체가 없음

## 대상

- `products` 테이블 총 1,173개 중 `판매중지` 21개 제외 → **약 1,152개** (등록완료 1,098 + 등록전 54)

## 핵심 방침

1. **초기화·삭제 없음**: 기존 데이터는 건드리지 않고 새 컬럼에 새 정보를 채운다. 준비 기간 내내 마켓 판매·가격수정·최저가 갱신 등 일상 업무는 그대로 유지된다.
2. **필수정보 수집**: Gemini 자동화가 아니라 **Claude가 대화 세션에서 직접 웹 조사** (제조사 공식 정보 기준)
3. **이미지 생성**: codex CLI의 GPT 이미지젠으로 로컬 생성 (저작권 문제 없는 신규 이미지)
4. **전환 방식**: 우리 사이트에서 1,152개 전부 완료한 후 → 쿠팡윙/ESM플러스/스마트스토어 상품 **전체 삭제 → 전체 신규 재등록** (공백은 재등록 기간 며칠뿐)
5. **백업 계정 미사용**: 별도 대시보드 계정 복사 대신 백업 테이블 + 엑셀 스냅샷으로 대체

## 단계별 계획

### 1단계. 안전장치 (기존 데이터 무변경)
- `products` 전체를 `products_backup_20260822` 테이블로 복사
- 전체 상품 엑셀 스냅샷 1부 로컬 보관

### 2단계. 스키마 확장 (새 컬럼 추가만, 기존 컬럼 무변경)
- `products`에 추가:
  - `item_info` (JSONB): 상품정보제공고시 실제 값 — 품목군별 항목 (제조사, 원산지, 용량/규격, 유통기한 표기방식, 소비자상담번호 등)
  - `rebuild_status` (TEXT): `대기` → `조사완료` → `이미지완료` → `재등록완료`
  - 신규 이미지 경로: 기존 `thumbnail_url`/`image_urls`/`detail_image_url`을 덮어쓰지 않고 `new_thumbnail_url`, `new_image_urls`, `new_detail_image_url`에 저장 (재등록 시점에 스왑)
- 마이그레이션 SQL은 `supabase/migrations/`에 추가, 수동 적용

### 3단계. 우선순위 정렬
- 위험도 순: ① 식품/음료 ② 브랜드 상품(대기업 제품) ③ 나머지
- 카테고리 기반 자동 분류 + 수동 조정

### 4단계. 배치 작업 (핵심, 약 한 달)
매 세션 반복:
1. 사용자가 배치 크기 지정 (예: 30개)
2. Claude가 상품별로 웹 조사 → `item_info` 채움 → `조사완료`
3. codex 이미지젠으로 썸네일/상세이미지 생성 → 업로드 → `이미지완료`
4. 사용자가 대시보드에서 검수, 이상 건만 수정
5. 진행률은 `rebuild_status` 집계로 항상 확인 가능 (중단 후 이어하기 지원)

### 5단계. 전환 (전량 완료 후)
1. 플레이오토 내보내기 수정: `"상세페이지 참조"` 하드코딩 제거 → 상품별 `item_info` 실값 사용, 신규 이미지 반영
2. 마켓 3곳 기존 상품 전체 삭제 (사용자 수동 or 지원 도구)
3. 수정된 엑셀로 전체 신규 등록 (새 판매자관리코드 자동 발급·매칭은 기존 기능 활용)
4. 재등록 완료 후 쿠팡/스마트스토어/ESM 셀러센터 양식 재임포트 → 가격·재고 동기화 재연결
5. 신규 이미지 컬럼을 본 컬럼으로 스왑, `재등록완료` 처리

## 영향 없음 확인

- 가격 관련 컬럼(`lowest_price`, `fixed_price_*`)은 이번 작업과 무관 — 최저가 자동 갱신(7:30/13:00/19:00) 정상 작동
- 주문/운송장/자동구매 흐름 무관
- 마켓 판매는 5단계 전환 전까지 전부 유지

## 에러/복구

- 모든 쓰기는 새 컬럼에만 → 실패해도 기존 운영 무영향
- 복구 경로: `products_backup_20260822` 테이블 또는 엑셀 스냅샷
- 배치 작업 중단 시 `rebuild_status`로 이어하기

## 검증

- 테스트 프레임워크 없음 → 각 단계 수동 검증
- 2단계 후: 기존 화면·내보내기 정상 동작 확인
- 5단계 첫 재등록은 소량(5~10개)으로 파일럿 후 전량 진행
